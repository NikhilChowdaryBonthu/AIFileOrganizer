# Demo guide

Use this short flow when showing the project to someone:

1. Open **AI File Organizer.app** with Ollama running.
2. Make a folder of disposable sample files, choose it with **Choose a custom folder to scan**, and enter `4` as the scan size.
3. Start a safe scan and show the review list with destination paths.
4. Untick one file and select an existing destination folder.
5. Show the duplicate finder. It checks selected scan results by file content.
6. Explain that every app managed move can be undone, while permanent deletion uses a separate confirmation.

The [desktop screenshot](desktop-screenshot.png) is rendered from the actual app interface using only synthetic CSV files. No personal files or details are shown.
